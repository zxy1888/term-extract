# Bilingual Term Extraction Tool
Python script for MTI translation study. It extracts bilingual term pairs from source and target text, exports result to Excel.

## Features
- Read English and Chinese term text
- Extract bilingual term pairs automatically
- Export term glossary to Excel

## Requirements
Python 3.8+
pandas
openpyxl

## Usage
1. Put term_extract.py, source_term.txt, target_term.txt in same folder
2. Install dependencies
